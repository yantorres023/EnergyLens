# Brand

## Status of "EnergyLens"

**Provisional — not cleared. Recommend renaming before store submission.**

Naming conflicts found (search extracts, S23; not a legal clearance):

* **Energy Lens** (energylens.com) — energy-management software (Excel add-in) by BizEE Software Ltd, a **UK** company, in the **same domain** (energy data). Highest risk: same market, same words.
* **EnergyLens** — a product name within BuildingLens (building automation / energy efficiency SaaS).

Same class (software, energy), same territory (UK) → material likelihood-of-confusion and passing-off risk, plus poor searchability.

## Voice

Plain, calm, numerate, non-judgemental. Numbers first. Never salesy, never "save £££", never blames the user. British English.

## Visual
